# 🛍️ E-Commerce Shopping Website

This e-commerce website built with **HTML, CSS, and JavaScript**. Includes product listings, cart functionality, and a clean UI.

🔗 **Live Demo:** [https://mdsarfarazali25.github.io/Shoping-We-Site/](https://mdsarfarazali25.github.io/Shoping-We-Site/)

---

## 🚀 Features
- **Product Catalog**: Display products with images, prices, and descriptions.
- **Shopping Cart**: Add/remove items, update quantities, and calculate totals.
- **Interactive UI**: Hover effects, dynamic cart updates, and smooth animations.
- **Local Storage**: Saves cart items even after page refresh.

---

## 🛠️ Technologies Used
- **Frontend**: HTML5, CSS3, JavaScript (ES6)
- **Version Control**: Git & GitHub
- **Hosting**: GitHub Pages

---
## 📦 How to Use
1. Open the live demo: [https://mdsarfarazali25.github.io/Shoping-We-Site/](https://mdsarfarazali25.github.io/Shoping-We-Site/)
2. Browse products.
3. Add items to the cart.
4. Proceed to checkout (note: this is a frontend demo; no real payments).
